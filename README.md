# Word Master — Word Puzzle Game

A lightweight, responsive word-unscramble game built with HTML, CSS, and vanilla JavaScript.

## How to play
1. Extract the ZIP file.
2. Open `index.html` in any modern browser.
3. Rearrange the displayed letters and type the correct word.
4. Select **Check answer**. Correct answers earn 10 points.
5. Use **Get a hint** if you need help, then move to the next level.
6. Complete all 8 levels and view your final score.

## Files
- `index.html` — game structure
- `style.css` — responsive visual design
- `script.js` — questions, scoring, hints, and game logic

No installation, internet connection, or external libraries are required.
